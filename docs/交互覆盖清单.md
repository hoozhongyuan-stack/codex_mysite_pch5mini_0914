# 全站交互覆盖清单

版本：V2.5.9；日期：2026-09-14；状态：本地实现，浏览器抽样验证，跨设备待验收。

本清单区分公共控件接入、页面业务状态和真实验收。公共样式存在不等于每个业务操作已经验收。

## 公共约定

- 网站：全局语义控件样式提供悬停、按压、focus-visible、禁用、忙碌和选择状态；H5使用按压，减少动态效果下关闭控件过渡。
- 网站导航：SiteLink处理常规站内页面；加载提示不占额外布局空间。认证跳转、下载/API、预览、外链、锚点和新窗口走原生行为；表单工作区页签保留专用客户端切换逻辑。
- 小程序：ActionView/Text/Image/Button/Input/Textarea处理按压、触摸移动取消、焦点及禁用回调；保留原生分享与表单控件。弹窗遮罩关闭及阻止冒泡不添加按钮反馈。
- 异步结果：沿用业务已有成功/失败文案，补充状态语义；本期不等于所有业务请求都已统一骨架、Toast或重试策略。

- `tests/interaction-navigation.test.mjs`：导航例外边界。
