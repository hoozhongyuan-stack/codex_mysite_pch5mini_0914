## 1. 产品目标与范围

1. 前台支持 PC、H5 和中英文切换，后台使用中文；预留多语言扩展能力。
2. 支持文章、展示型商品、表单、素材、访客、管理员、导航、主题及网站设置。
3. 便于搜索引擎和 AI 检索内容，提供访问线索及人工引用证据记录。
4. 商品提供规格、价格、库存及询价；新增实物订单、购物车、线下付款审核、发货签收和整单售后，详见 ORD-001—021。在线支付不在首期。
5. 最终目标是私有化部署。先本地完成并由用户验收，再单独推进生产部署。
6. 保留既有业务内容、素材和提交记录；数据清理不得以需求升级为由默认执行。

## 2. 用户角色与后台信息架构

### 2.1 角色

| 角色 | 范围 |
| --- | --- |
| 未登录访客 | 浏览已发布内容、查看商品、提交公开表单、注册 / 登录 |
| 登录访客 | 使用邮箱账号或沙箱测试身份登录；不获得后台权限 |
| 内容编辑员 | 管理内容、分类与素材；不可访问私有提交、访客管理及系统配置 |
| 站点管理员 | 管理全部后台模块、子账号和操作日志 |

现有两位主账号均获准进入后台；管理员账号清单以系统配置为准，本文档不保存登录凭据。

### 2.2 菜单

总览、文章管理、文章分类、商品管理、商品分类、导航管理、表单管理、表单列表、素材中心、管理员、访客用户、操作日志、协议与政策、GEO 洞察、主题模板、网站设置。

- “表单管理”维护表单定义；“表单列表”处理实际提交，两者独立。
- “操作日志”独立于管理员页面。
- 素材与一级文件夹合并到“素材中心”，不再要求在两个菜单间切换。
- 网站设置内包含品牌设置、页脚配置、登录与注册配置、SMTP 配置。

### 安全与部署约束

- 2026-09-23 新需求取代原环境变量优先的后台操作流程：AppID / AppSecret 复用后台小程序登录配置，AppSecret 由身份服务加密保存；上传密钥由站点所有者经受限后台接口写入 Web 专用私有目录，并保留既有服务器文件路径作为兼容方案。微信代码上传 IP 白名单仍需在微信公众平台维护。提交审核时由身份服务取得临时令牌，不在后台要求操作者填写 `WECHAT_MINI_ACCESS_TOKEN`。
- 后台只显示脱敏 AppID、密钥是否存在和路径有效性，不展示密钥内容。微信 CI 输出会清理 AppID、密钥路径和疑似私钥内容后再保存到发布记录。
- 本期不新增生产依赖；执行时通过服务端 `npx` 调用固定版本 `miniprogram-ci@2.1.31`，同一 Web 进程只允许一个微信 CI 任务执行，并限制子进程输出缓冲大小。
- 生产 Docker 的密钥与发布记录挂载到 Web 专用持久目录；Web 进程在准备挂载目录后以非 root 用户运行。其他部署方式需自行提供受保护的持久目录，否则回退到本地私有目录或临时记录路径。
