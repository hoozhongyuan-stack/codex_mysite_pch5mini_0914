# 后台界面统一规范与验收清单

版本：V2.8.0，2026-09-21。状态：本地实现；公共组件浏览器验证已进行，真实后台全量验收待登录，未部署 UAT。

## 本次解决的根因

原后台将按钮、输入框、筛选栏、弹窗宽度分散在多个模块和全局样式中，存在重复覆盖；部分三级详情依赖内存状态，地址与面包屑不反映当前位置。此次以公共样式、字段、页头、分页、栏目、详情导航和弹窗为统一入口，移除已被公共规则取代的模块尺寸声明。

## 必须沿用的规则

| 部位 | 规则 |
| --- | --- |
| 页面结构 | 页头 / 栏目 / 筛选 / 批量栏 / 主内容 / 分页；主要操作在页头或表单底部 |
| 控件高度 | 桌面普通按钮和输入框 36px；表格行内按钮 30px；窄屏控件 40px |
| 字段宽度 | short 160px，用于数字；standard 240px，用于选择；wide 420px；full 填满当前表单列。宽度以语义选择，不能逐页手写 |
| 筛选 | 常用筛选在首行；共享列表的次要筛选收在“更多筛选”；查询和重置成组，字段不填满剩余整行 |
| 排版 | 正文 13–14px，辅助文字 12px；表单最多双列，窄屏单列；保留后台紫色识别体系 |
| 弹窗 | sm 560 / md 800 / lg 1000 / editor 与 media 1200px，上限服从屏幕；保存栏粘附底部，取消在保存之前 |
| 编辑保护 | 修改后取消、关闭、Esc、点遮罩统一确认；未修改关闭不打扰；成功保存关闭不出现丢弃提示；分区保存只清除本区脏状态 |
| 异步反馈 | 保留加载、成功、失败、重试与禁用状态；进行中的按钮用统一加载反馈，防止重复提交 |
| 导航 | 沙龙活动、视频系列、订单详情使用地址参数；设置、积分商城、账号权限等栏目地址可恢复；返回详情列表时保留筛选参数 |
| 数字输入 | 隐藏浏览器上下增减箭头；保留数字输入、校验能力 |

## 自动回归约束

- 新增后台入口必须补充页面模板与子页面清单，测试核对所有 workspaceViews。
- 后台弹窗必须从 admin-dialog 引入，避免绕过统一宽度与关闭保护。
- 业务模块不得给按钮、输入框、选择框、文本域、弹窗写内联尺寸。
- 导航测试验证详情参数变更保留分页、筛选及安全编码，面包屑反映实际详情。
- 编辑保护测试验证各种关闭来源，以及分区保存不会误清除其他草稿。
- 此类源码约束不能替代浏览器业务验收。

## 可操作的公共组件验收页

从项目根目录启动：

```sh
./node_modules/.bin/vite --config docs/design/admin-system/vite.config.mjs
```

地址：http://127.0.0.1:3018/ 。直接导入当前后台真实公共组件和样式，无业务接口、无真实会员数据。保存只是模拟反馈，不写入后台。此页不是产品后台，也不是 UAT。

### 已观察的浏览器结果

- 1366×768：编辑型弹窗宽 1200px、高 720px，底部保存栏仍在视口内；小型弹窗宽 560px，无横向溢出。
- 1440×900：配置页普通控件高 36px；数字框宽 160px、选择框宽 240px；内容区未横向溢出。
- 1920×1080：展开筛选后搜索宽 280px、其他筛选宽 200px、高度均 36px，未因剩余空间拉宽。
- 修改名称后取消，出现未保存确认；拒绝放弃后保留已编辑名称；保存中按钮禁用，模拟保存成功后弹窗关闭。
- 未编辑的小弹窗点击关闭直接退出；公共栏目切换更新地址，浏览器返回恢复原栏目。
