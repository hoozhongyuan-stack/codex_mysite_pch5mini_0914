基础配置　/　首页装修
底部导航　/　版本与检查

商品、订单、积分继续共用原后台。
本稿展示的 5 个导航为示例，可配置 2–5 个或关闭。

双支付与悬浮入口

线下付款、微信支付分别启用。
结算时选择，支付结果由服务端确认。

每端最多 3 个悬浮入口：图片 / 电话 / 表单。
本稿展示 2 个；弹窗及键盘出现时隐藏。

视觉与验收标准

统一线性图标、44px触控区域。
内容优先，留白适度，图片比例统一。

设计示例：价格、积分、商品及会员均非真实配置。确认视觉后分阶段开发；开发者工具检查与 iPhone / Android 真机验收分别记录。本稿不修改任何业务数据。
